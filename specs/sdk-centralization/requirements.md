| ID | Requirement | Acceptance |
|---|---|---|
| `CONN-FIREFLY-III-MCP-SDK-CENTRALIZATION-R001` | **Governed HTTP.** The connector must reach Firefly III only through the SDK governed HTTP client in `firefly_iii_mcp/api/api_client_base.py`. It must not import `requests`. Caller chain: any Firefly tool (`firefly_iii_mcp/mcp/mcp_*.py`) -> `get_client` (`firefly_iii_mcp/auth.py` line 141) -> `ApiClientBase` (`firefly_iii_mcp/api/api_client_base.py` line 50) -> `create_http_client` (line 62) from `scion_sdk.http.client`. Shape: `ApiClientBase.__init__` builds `self.session` with `create_http_client(HttpClientOptions(...))` and imports no `requests`; `tests/test_sdk_centralization.py::test_api_client_uses_sdk_http_client` asserts an `httpx.Client` and scans the package source. | `tests/test_sdk_centralization.py::test_api_client_uses_sdk_http_client` must observe an SDK client and no `requests` import. |
| `CONN-FIREFLY-III-MCP-SDK-CENTRALIZATION-R002` | **Adopt scion-sdk 0.10.0 import paths.** firefly-iii-mcp must import only paths that exist in `scion-sdk` 0.10.0 and must raise its floor to that release. The release removes the pre-layer paths without an alias (`SCION-CENTRALIZED-CAPABILITIES-R046`). Stage: dependency and import adoption. Edits, by file: `firefly_iii_mcp/api/api_client_base.py`: `create_http_client` to `build_http_client(options)`; `firefly_iii_mcp/auth.py`: `create_http_client` to `build_http_client(options)`; `tests/test_auth.py`: `create_http_client` to `build_http_client(options)`. Raise the `pyproject.toml` requirement `scion-sdk[mcp]>=0.6.4,<0.7.0` to `scion-sdk>=0.10.0,<0.11.0` with the same extras and regenerate `uv.lock`. A client built by the old factory keeps its options argument; `build_http_client(options, async_=True)` returns the async client. No wrapper, alias or fallback import stays. Caller chain: the connector entry point `firefly_iii_mcp` -> its modules above -> the public `scion_sdk` modules. Shape: import edits in the files named, one `pyproject.toml` edit and one lock edit; the new test reuses `ast` from the standard library. Depends on: SCION-CENTRALIZED-CAPABILITIES-R046. | Test: `tests/test_scion_sdk_0_10_imports.py::test_every_scion_sdk_import_resolves_on_the_pinned_release` (L2) parses every Python file of `firefly_iii_mcp` and `tests` and asserts each imported `scion_sdk` module resolves with `importlib.util.find_spec`. |
